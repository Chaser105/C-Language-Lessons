# Архив занятий по языку Си (Стивен Прата)

В этом репозитории собраны практические задания и листинги по ходу изучения книги Стивена Прата.

## ⚠️ Важный нюанс структуры проекта

Нумерация папок в этом архиве сдвинута относительно глав учебника:
* **1. Text output** — относится ко **2 главе** учебника
* **2. Data types** — относится к **3 главе** учебника
* **3. Strings and formatted** — относится к **4 главе** учебника
* **4. Operations** — относится к **5 главе** учебника
* **5. Control statements** — относится к **6 главе** учебника
* **6. Branching and transitions** — относится к **7 главе** учебника
* **7. Symbolic input-output** — относится к **8 главе** учебника
* **8. Functions** — относится к **9 главе** учебника
* **9. Arrays and pointers** — относится к **10 главе** учебника
* **10. Сharacter strings** — относится к **11 главе** учебника
* **11. Memory management** — относится к **12 главе** учебника
* **12. File input-output** — относится к **13 главе** учебника
* **13. Structures** — относится к **14 главе** учебника
* **14. Bit operation** — относится к **15 главе** учебника
* **15. Preprocessing** — относится к **16 главе** учебника
* **16. Advanced view** — относится к **17 главе** учебника

> 📌 **Обратите внимание:** Внутри каждой папки (упражнения) собраны **абсолютно все листинги** соответствующей главы книги.

## 🧹 Очистка от мусора
Проект полностью очищен от тяжелых временных файлов компилятора Visual Studio (`Debug/`, `Release/`, `x64/`, `.vs/`). В репозитории хранится только чистый исходный код программ.
