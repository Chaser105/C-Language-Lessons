№
Что
значит
«монопольный
(эксклюзивный)
режим»?
Когда
файл
успешно
открывается
с
буквой
"х",
операционная
система
блокирует
его
«намертво».
Ни
одна
другая
программа
на
компьютере
(даже
Блокнот
или
Word)
не
сможет
даже
просто
открыть
этот
файл,
пока
ваша
программа
его
не
закроет
через
fclose.
"rb"
(Read
Binary)
-
Открывает
существующий
файл
только
для
чтения
в
двоичном
режиме.
Если
файла
нет
-
вернет
ошибку.
"wb"
(Write
Binary)
-
Открывает
файл
только
для
записи
в
двоичном
режиме.
Если
файл
уже
был
на
диске,
он
полностью
затирается
(очищается
до
нуля).
Если
файла
не
было
-
создается
новый.
"ab"
(Append
Binary)
-
Открывает
файл
для
добавления
данных
в
конец
в
двоичном
режиме.
Старые
данные
не
стираются.
Всё,
что
вы
пишете,
автоматически
дописывается
в
самый
конец
файла.
Если
файла
нет
-
создается
новый.
"wb+"
и
"w+b"
-
Это
абсолютно
одно
и
то
же,
просто
буквы
можно
менять
местами.
Плюс
(+)
означает
расширение
возможностей.
Этот
режим
открывает
файл
для
записи
И
для
чтения
одновременно
в
двоичном
режиме.
Но
помните:
старый
файл
при
этом
всё
равно
затирается
до
нуля.
"ab+"
-
Открывает
файл
для
добавления
в
конец
И
для
чтения
в
двоичном
режиме.
Старый
файл
не
стирается,
вы
можете
читать
его
с
любого
места,
но
любая
запись
всё
равно
принудительно
уйдет
в
самый
конец
файла.
